# 立体仓库三维模型

基于参考图搭建的 Three.js 场景。入库区包含自动滚筒交接、货架端部的双轨移载和右侧的人工入库口。出库区包含车道、龙门架、回形滚筒线和蓝色升降机。十六列白色货架分为四组，每端八条接驳轨道，每条对应两列。正面设黄色防护网，三条巷道内设地轨和顶部导轨。照片中的单立柱堆垛机布置在中间巷道。三台桥式行车沿前后方向跨越作业区。仓库四周设浅色压型板外墙、混凝土墙裙、分格窗和装卸门洞。坐标单位为米，墙体、设备尺寸及相对位置按参考图估算。

## 本地运行

使用 Node.js 22.12 或更高版本。

```powershell
npm ci
npm run dev
```

打开终端显示的本地地址。通过 **总览**、**入库区**、**出库区** 切换区域。总览默认显示外墙，进入入库区或出库区会自动隐藏外墙，视口右上角的外墙按钮可以切换显隐。入库区右下角可查看 **输送近景**、**货架侧面** 和 **人工入库口**，出库区可查看 **出库输送近景**、**货架端部** 和 **巷道堆垛机**。右侧可展开区域并选择或隐藏单个设备。**导出 GLB** 始终包含完整场景。运行 `npm run build` 可生成静态构建产物。

同一局域网的手机或电脑可打开 `npm run dev` 输出的 **Network** 地址，默认端口为 5173。预览构建产物时运行 `npm run preview`，默认端口为 4173。

点击场景中的人物或 **数字人** 按钮选中角色，再用 **WASD / 方向键** 走动。人物平滑加速，按住 **Shift** 冲刺，松开后减速到步行；停止方向输入会立即停下。切换区域和预设视角时仍可控制人物，点击 **跟随** 可让相机跟随人物。触屏可在选中后使用视口左下角的方向键，同时按住 **冲刺** 按钮加速。

再次点击人物、点击场景其他位置或按 **Esc** 可取消选中。此时 **W / ↑** 和 **S / ↓** 沿视线飞行，**A / ←** 和 **D / →** 左右飞行，**E / Q** 上升和下降。相机以固定速度移动，可以穿过仓库模型。飞行时按住鼠标左键拖动可原地转向，滚轮可缩放。

数字人与其待机、走路、冲刺动画随仓库一起导出到 GLB。

## 调整模型

`src/model.js` 中的 `createLoadingStation()` 返回仓库根节点及各设备组。`warehouse` 定义场地范围、区域间距与货架配置，各设备的尺寸和布局由对应建模函数控制。模型可以直接加入其他 Three.js 场景，导出的 GLB 也可以通过 Three.js 的 `GLTFLoader` 加载。
